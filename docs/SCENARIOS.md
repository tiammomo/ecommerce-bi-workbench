## 真实进程重启验收

执行 `cd apps/api && uv run python ../../scripts/verify_persistence.py`，在独立临时目录中迁移和初始化 SQLite，启动两个不同 PID 的真实 FastAPI 进程。该脚本同时把演示 CSV、模板与日志重定向至临时目录，不使用正常工作区数据库。

已通过9项检查：成本版本、月度目标、保存视图、业务修订号在重启后保持；未来成本不改变历史订单指标；普通seed跳过且不覆盖修改；重启后的同一幂等键返回原操作结果；显式恢复重置成本/目标/视图且业务修订号从4增至5。首次完整执行耗时12.14秒。

CSV测试另覆盖分笔外币退款舍入：支付0.02原币、汇率1.5时收入为人民币3分，两笔0.01原币退款按累计转换差额分别为2分和1分，总计精确抵销3分。19项CSV测试通过。
