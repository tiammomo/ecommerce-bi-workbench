# 实施决策

- 第一版按完整规格实现本地单工作区，后端实际读写 SQLite；业务数据是截至 2026-09-28 的固定模拟数据。
- 浏览器通过 FastAPI 查询经营数据，正式核算、试算、导出共用后端口径。金额在 API 中为十进制字符串。
- SQLite 保存整数分；单位成本保存万分之一元，汇率保存亿分之一。Decimal 负责乘除与舍入。
- 成本版本按店铺、渠道、基础依次匹配订单日期，订单保存快照。预览不改变正式数据，历史变更需显式重算。
- 视图、目标、成本和导入批次保存在数据库；URL 负责可恢复筛选，浏览器仅保留显示偏好。
- 产品定位为帮助老板判断经营结果的 BI 看板。配色参考 [Mamoji](https://github.com/tiammomo/Mamoji)：冷灰背景 `#f4f6fa`、白色卡片、蓝色主色 `#3659e3`、紫色辅色 `#8b5cf6`；文字分为 `#111827`、`#344054`、`#667085` 三层。导航、按钮、重点指标和图表用蓝紫色强调，品牌及细装饰线采用小面积蓝紫渐变。保留大字号和明亮的阅读区域。
- 涨跌按数值方向统一为红涨、绿跌、持平灰色；退款率和成本上涨同样为红色，不按经营好坏反转。未知数据保持未知，负基数比较保留绝对变化或由亏转盈说明，不伪造增长率。瀑布图增加为红、扣减为绿、总计使用蓝紫主题色；经营风险以琥珀提示及明确文字表达，与涨跌方向分开。
- 视觉以可读性为先：正文、金额明细与输入控件 14px，导航与重点文字 15px，辅助信息 13px，模块标题 18px，桌面核心指标 34px；图表坐标与图例 13px、提示框 14px。行高、图表高度和控件空间随字号一起调整，较窄屏幕使用换行及表格容器内滚动。渠道颜色在各页保持一致。
- 默认开发服务只监听本机。平台实际授权、原始平台报表适配和公网部署不属于本版本。

本文件记录方案，实际运行与验证结果见 README 和 VALIDATION.md。
