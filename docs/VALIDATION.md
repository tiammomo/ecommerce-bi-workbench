## 浏览器验收内容

17 项全栈测试包含：

1. 整体与渠道、店铺、SKU 分组对账，过滤后的 CSV 全量导出。
2. 保存视图落库与刷新恢复；商品、平台 Listing 的导出维度与当前选择一致。
3. 未来成本预览与幂等确认，历史经营利润保持不变。
4. 通过成本页维护 SKU071 历史成本，再显式补全，核算覆盖率变为 100%；两次不同成本试算产生不同结果，正式数据与修订号保持原值。
5. 通过报表中心下载模板、上传 CSV、预览并确认；篡改相同业务键记录后确认按钮禁用，可下载错误说明。
6. 通过真实筛选控件选择 Temu 与 Nestora US，核对 KPI、导出参数、浏览器前进后退。
7. 月度目标写入后更新总览；切换月份不会复用前一月份的输入值。
8. 退款支付归属和退款发生时间的结果不同，事件口径不展示误导性退款率；刷新后选择保留。
9. 成本对照展示基础、渠道、店铺三层来源，明细抽屉保持在视口内。
10. 八个业务页面加载真实 API 数据，无浏览器脚本异常；URL 筛选刷新后保持。
11. 仅在服务失败恢复测试中临时中断 analytics 网络请求，显示可操作的重试入口；解除中断后重新查询真实 API。其他测试不伪造 API 数据。
12. 总览与成本页在 1440px、1280px 下无页面级横向溢出，另保存 768px 总览；大型明细表在自己的容器内横向滚动。

此外，持久化脚本在两个不同的真实 API 进程之间核对成本、目标、视图、修订号与幂等回执；重复 seed 保留修改；显式恢复演示数据撤销测试修改，并把业务修订号由 4 增至 5。
